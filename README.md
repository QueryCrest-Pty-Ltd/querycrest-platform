# QueryCrest Platform

South Africa's student application and university journey platform.
Helping students apply, find accommodation, and access funding —
all in one place.

## Tech Stack
- HTML5, CSS3, JavaScript
- Supabase (database, auth, edge functions, storage)
- Resend (email)
- PayFast (payments)

## Project Structure
- /pages        → all website pages
- /css          → stylesheets
- /js           → JavaScript files
- /images       → all images and assets
- /account      → login, signup, dashboard
- /supabase     → edge functions

## Getting Started
1. Clone the repository
2. Open index.html in your browser for static pages
3. For edge functions, install Supabase CLI
4. Never commit .env files or API keys

API Fundamentals Question 1 / 10

1. A developer needs to update only the email address of an existing user record through a REST API, leaving all other fields unchanged. Which HTTP method is the correct choice and why?

2. An authenticated user tries to access an admin-only dashboard endpoint. The server correctly returns a 403. A junior developer argues the server should return 401 instead, saying "both mean access was denied." What is wrong with that reasoning?

3. This function is meant to return the parsed user data from an API, but it keeps returning unexpected values. What is wrong?

async function getUser(id) { const res = await fetch(`/api/users/${id}`); const data = res.json(); return data; }

4. A developer designs a REST API with the endpoint POST /api/getUserData. A senior engineer rejects it in code review. What specific REST design principle is being violated?

5. A developer enables Row Level Security (RLS) on a Supabase table but does not create any policies. What happens when an authenticated user sends a SELECT query to that table?

6. A developer stores the Supabase service role key directly inside a React frontend component to make database calls. What is the critical security risk of this approach?

7. This function sends a POST request and gets a 200 response, but the server always fails to read the request body. What is the missing piece?

async function createUser(userData) { const res = await fetch('/api/users', { method: 'POST', body: JSON.stringify(userData) }); return res.json(); }

8. A startup wants to build a mobile app with user authentication, a relational database, and file storage — without managing their own servers. A developer recommends Supabase. Which description best explains why Supabase fits this requirement?

9. Study this Promise chain carefully. If the API returns an empty array [], what gets logged to the console?

fetch('/api/items') .then(res => res.json()) .then(data => { if (data.length === 0) throw new Error('No items found'); return data; }) .catch(err => { console.log('Caught:', err.message); return []; }) .then(result => console.log('Result:', result));

10. A developer runs this Supabase query expecting to get only orders belonging to users named "John". What unexpected result will actually be returned?

const { data, error } = await supabase .from('orders') .select('id, total, users(id, name)') .eq('users.name', 'John');
